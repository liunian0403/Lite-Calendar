轻历（QingLi）1.0.0
====================

一个本地优先的 Windows 日程与提醒应用：月 / 周 / 日三种视图，事件增删改查，
每天 / 每周 / 每月 / 工作日重复，到点提醒（托盘常驻 + 右下角气泡），ICS 导入导出，
事件搜索，左侧迷你月历定位。全部数据保存在本机，不联网。

启动方式
--------
开始菜单 → 轻历
（安装时勾选“创建桌面快捷方式”则桌面上也有图标）

功能清单
--------
视图
  · 月 / 周 / 日 三种视图，右上角分段控件切换（快捷键 Ctrl+1 / Ctrl+2 / Ctrl+3）
  · 左上角 ‹ › 翻页、“今天”按钮一键回到今天；默认定位到今天
  · 周 / 日视图带当前时刻指示线，可滚轮上下滚动，双击空白处新建
  · 月视图双击空白格新建，右键弹出“新建 / 编辑 / 删除”

日程字段
  · 标题、开始 / 结束时间、全天、地点、备注、提醒、颜色
  · 重复：不重复 / 每天 / 每周 / 每月 / 工作日（周一至周五），可设重复截止日
  · 提醒：不提醒 / 开始时 / 提前 5 / 15 / 30 分钟 / 1 小时 / 1 天
  · 重复日程支持“仅此一次”或“整个系列”的编辑与删除（删除单次会记住排除项）

数据
  · 保存在 %APPDATA%\QingLi\data.xml，每次修改立即落盘，重启不丢
  · 不依赖任何联网服务；状态栏右侧显示日程总数

其他
  · 左侧迷你月历：点击日期跳转，带事件小圆点，可翻月
  · 左侧“当日日程”列表：点击条目直接编辑
  · 系统托盘常驻：关闭窗口最小化到托盘（气泡提示一次），托盘菜单可新建 / 打开 / 退出
  · 到点提醒：右下角气泡（不抢焦点），支持“5 分钟后提醒”与“知道了”
  · 顶部搜索：按标题 / 地点 / 备注过滤，回车打开第一条
  · ⋯ 菜单：导入 ICS、导出全部日程为 ICS、打开数据文件夹、关于

快捷键
------
  Ctrl+N        新建日程（当前选中日期）
  Ctrl+F        聚焦搜索框
  Ctrl+1/2/3    月 / 周 / 日视图
  T              回到今天
  方向键         月视图中移动选中日期
  Enter          在选中日期新建日程
  Esc            关闭搜索 / 对话框

系统要求
--------
  Windows 7 SP1 及以上（Windows 10 / 11 体验最佳）
  需要 .NET Framework 4.6+（Windows 10 / 11 已内置）

数据文件
--------
  %APPDATA%\QingLi\data.xml

卸载
----
  设置 → 应用 → 轻历 → 卸载
  或开始菜单 → 卸载 轻历
  卸载结束时会询问是否同时删除本机的日程数据（勾选即彻底清理，不留残留）
