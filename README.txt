轻历（QingLi）1.2.0
====================

一个本地优先的 Windows 日程与提醒应用：月 / 周 / 日三种视图，日程增删改查，
每天 / 每周 / 每月 / 工作日重复，到点提醒（托盘常驻 + 右下角气泡），ICS 导入导出，
事件搜索，中国法定节假日与调休自动展示，左侧迷你月历定位。
日程数据只保存在本机，不注册账号、不上传云端；只有节假日数据会在运行时从
公开数据源拉取并本地缓存，断网时使用内置数据。

完整文档（含构建、测试、已知限制）：
https://github.com/liunian0403/Lite-Calendar


启动方式
--------
开始菜单 → 轻历
（安装时勾选“创建桌面快捷方式”则桌面上也有图标）


30 秒上手
---------
· 月视图空白处双击 = 新建；Ctrl+N 也可以
· 顶栏“今天”或按 T = 回到今天
· Ctrl+F = 搜索标题 / 地点 / 备注 / 节假日
· Ctrl+1 / 2 / 3 = 月 / 周 / 日视图
· Ctrl+Shift+L = 循环切换主题
· 点窗口关闭按钮只是隐藏到托盘，提醒继续；要退出用托盘右键 →“退出”


功能清单
--------
一、看日历
  · 月 / 周 / 日三种视图，右上角分段控件切换
  · 左上角 ‹ › 翻页；“今天”按钮一键回到今天
  · 启动时定位到今天；切换视图会保留当前浏览的日期
  · 周 / 日视图带当前时刻指示线和 24 小时刻度，可滚轮 / 拖动滚动条 /
    PageUp / PageDown 滚动
  · 时间重叠的日程自动并排；顶部有全天事件条（每天最多显示 2 条）
  · 月视图事件块放不下时显示“还有 N 项”
  · 点击周 / 日视图的日期表头可选中该日，左侧栏同步

二、日程字段
  · 标题、开始 / 结束时间、全天、地点、备注、提醒、8 色标记
  · 支持跨天日程；全天日程的结束日期包含当天
  · 开始 / 结束可点日期框弹出迷你月历选择
  · 时间分钟以 5 分钟为步长，编辑旧日程时保留原分钟值
  · 新建日程默认选中“提前 15 分钟”提醒，可改为“不提醒”
  · 编辑已有日程时对话框左下角有“删除”按钮
  · 编辑对话框内 Ctrl+S = 保存，Esc = 取消

三、重复
  · 不重复 / 每天 / 每周 / 每月 / 工作日（周一至周五）
  · 每周：与开始日期同一个星期几
  · 每月：与开始日期同一个“日”；该月没有这一天时收敛到月末
    （31 号 → 2 月 28/29 日、4 月 30 日）
  · 工作日：只按星期几判断，不跳过法定节假日与调休
  · 可设“重复截止”日期（含截止日当天），不设则长期重复
  · 修改 / 删除重复日程可选“仅此一次”或“整个系列”
  · 删除单次会记住排除项，重启后仍生效

四、提醒
  · 不提醒 / 事件开始时 / 提前 5 / 15 / 30 分钟 / 1 小时 / 1 天
  · 应用每 20 秒扫描一次；到点弹右下角气泡，不抢焦点
  · 气泡停留 25 秒后自动关闭，弹出时播放一次提示音，多个提醒向上堆叠
  · 气泡按钮：“5 分钟后提醒”“知道了”；点气泡其他区域打开该日程
  · 提醒依赖应用在运行；未运行期间错过的提醒不会补发
  · “5 分钟后提醒”只存在内存，退出应用后失效

五、搜索
  · 按标题 / 地点 / 备注过滤，边输入边显示，最多 8 条
  · 日程结果按与当前时间的距离排序；重复日程按主记录显示
  · 支持节假日中文名与英文别名：
      元旦 new year
      春节 spring festival / chinese new year / cny
      清明 qingming / tomb sweeping
      劳动 labour day / labor day / may day
      端午 dragon boat
      中秋 mid autumn / moon festival
      国庆 national day
  · 输入 holiday / vacation / 节假 / 节假日 / 假期，列出最近 3 个节假日
  · 输入 calendar / calander / cal 回车，回到今天
  · ↑ ↓ 选择结果，Enter 打开，Esc 清空并关闭

六、节假日与调休
  · 启动时后台拉取当年与次年数据，依次尝试 jsDelivr、fastly、GitHub 源站
  · 缓存到 %APPDATA%\QingLi\holidays-年份.json；断网时用缓存或内置快照
  · 数据来源：holiday-cn（依据国务院办公厅节假日安排公告整理）
  · 月视图显示“休”（法定放假）/“班”（调休上班）徽标和节日名
  · 周 / 日视图表头显示节日名或“班”
  · 迷你月历用红字标放假、调休上班的周末按工作日颜色（无徽标）
  · 左侧“日程”标题和状态栏也会显示当天节假日信息
  · 次年安排通常当年 11–12 月公布，公布前次年数据为空

七、ICS 导入导出
  · ⋯ 菜单 → 导入 ICS 日历 / 导出全部日程为 ICS
  · 导出整个日程库，默认文件名 轻历-年月日.ics
  · 支持 RRULE、VALARM、全天事件、UTC 时间、特殊字符转义
  · 导入支持 DTSTART / DTEND / DURATION、VALARM、RRULE 的
    FREQ / BYDAY / UNTIL / COUNT，以及折行的 ICS 文件
  · 导入时“标题 + 开始时间”完全相同的日程会跳过，其余新增
  · 已知限制：导出不折行、不写 EXDATE（单次排除项）；
    时区 TZID、INTERVAL、BYMONTHDAY 等参数不解析，详见完整文档

八、主题
  · 三档：跟随系统 / 始终浅色 / 始终深色
  · 入口：⋯ → 主题；托盘右键 → 主题；Ctrl+Shift+L 循环切换
  · 选中即生效、立即写盘，不重启；已打开的对话框和提醒气泡同步换色
  · 跟随系统：读取 Windows 应用模式，系统切换后自动跟随
  · 默认值：全新安装跟随系统；从 1.1.0 升级默认始终深色
  · 8 色事件色板在深浅主题下分别取色，索引与日程对应关系不变
  · 深浅标题栏通过 DWM 切换；Win7 / 关闭 DWM 时标题栏保持系统浅色
  · 系统“删除确认 / 关于”弹窗不随主题变化

九、托盘与后台
  · 关闭窗口（含 Alt+F4）隐藏到系统托盘，首次隐藏提示一次
  · 双击托盘图标恢复窗口
  · 托盘菜单：打开轻历 / 新建日程 / 今天 / 主题 / 退出
  · 提醒在托盘状态下继续生效；退出时保存数据
  · 单实例：重复启动只会把已运行的窗口置前
  · ⋯ 菜单：导入 / 导出 ICS、主题、打开数据文件夹、关于
  · 未做开机自启 / 计划任务


快捷键
------
主窗口
  Ctrl+N        新建日程（选中日期 09:00）
  Ctrl+F        聚焦搜索框并全选
  Ctrl+1/2/3    月 / 周 / 日视图
  Ctrl+Shift+L  循环切换主题（跟随系统 → 始终浅色 → 始终深色）
  T              回到今天
  方向键         月视图移动选中日期
  Enter          月视图在选中日期新建日程
  Esc            关闭搜索

搜索框
  ↑ / ↓          移动选中结果
  Enter          打开当前结果
  Esc            清空并关闭

周 / 日视图（网格获得焦点时）
  ↑ / ↓          滚动
  PageUp/PageDown 按视口高度滚动
  鼠标滚轮        滚动

编辑对话框
  Ctrl+S         保存
  Esc            取消


数据与隐私
----------
· 日程：%APPDATA%\QingLi\data.xml，每次修改立即落盘
· 备份：data.xml.bak（存在时）
· 损坏文件：data.xml.corrupt-时间戳（不会自动从 .bak 恢复）
· 节假日缓存：%APPDATA%\QingLi\holidays-年份.json（可安全删除）
· 崩溃日志：%TEMP%\QingLi-crash.log
· 日程不上传任何服务器；唯一网络请求是拉取节假日 JSON
· 换电脑：退出应用后复制 %APPDATA%\QingLi 到新机器同一位置


安装 / 升级 / 卸载
------------------
· 安装包：QingLi-Setup-1.2.0.exe，中文向导，免管理员权限
· 安装到 %LOCALAPPDATA%\Programs\QingLi
· 安装时可勾选创建桌面快捷方式（默认不勾选）
· 升级：直接覆盖安装，%APPDATA%\QingLi 中的日程与缓存保留
· 卸载：设置 → 应用 → 轻历 → 卸载，或开始菜单 → 卸载 轻历
· 卸载结束时会询问是否同时删除日程数据；选“否”即保留

  注意：静默卸载（/VERYSILENT 或 /SILENT）不会弹询问框，会直接删除
  %APPDATA%\QingLi 下的日程与缓存数据。日常卸载请用上面的交互方式，
  在弹窗里选“否”即可保留数据；脚本化卸载前请先备份 %APPDATA%\QingLi。


系统要求
--------
Windows 7 SP1 及以上（Windows 10 / 11 体验最佳）
需要 .NET Framework 4.6+（Windows 10 / 11 已内置）


已知限制（摘要）
----------------
· 重复日程“仅此一次”编辑会生成独立日程并排除原系列该次；排除项无法在界面恢复
· 工作日重复不跳过法定节假日；调休上班的周末也不会自动补
· ICS 导出不折行、不写排除项；TZID / INTERVAL / BYMONTHDAY 等不解析
· ICS 导入按 UTF-8 读取，非 UTF-8 文件可能乱码
· 提醒依赖应用运行，错过不补发；托盘常驻时照常提醒
· 周 / 日视图全天事件每天最多显示 2 条
· 不显示农历、节气、自定义纪念日；不支持多日历 / 分类 / 云同步
· 保存失败（磁盘满、权限异常）不会弹窗提示，请定期备份
· 按系统 DPI 缩放，未做多显示器混合 DPI 自适应
· 安装包未签名，首次运行可能弹 SmartScreen“未知发布者”
· 深色主题下多行备注框滚动条、系统消息框不随主题变化
· 次年节假日依赖上游公布时间，通常当年 11–12 月才有
